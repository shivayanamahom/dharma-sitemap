# История изменений

## 0.3.2 — 2026-10-16

### Исправлено

- В карту не попадала страница «Список товаров» (корень каталога, пункт меню со списком всех товаров): корень категорий, брендов и бейджей Dharma Shop (id 0 или 1) считался сущностью, а источники сущностей отдают только записи с id больше 1. Теперь корень берётся из меню.
- Страница-корень брендов и бейджей без пункта меню (например, `/component/dharmashop/badge`) тоже добавляется, если есть что показывать. Если пункт меню есть, берётся его адрес без дубля.

## 0.3.1 — 2026-10-16

### Исправлено

- В меню админки Joomla вместо названия компонента отображался ключ `COM_DHARMASITEMAP_TITLE`: заголовок пункта меню переводится только из `.sys.ini`, а ключа там не было. Ключ добавлен в оба языка.
- Лента обновлений указывала `client = administrator`, поэтому Joomla не показывала обновление пакета; теперь `site`, как у всех пакетов.
- Проверка языковых файлов в CI теперь следит, чтобы ключи из манифестов (название, пункт меню) были определены в `.sys.ini`.

## 0.3.0 — 2026-10-16

Карта теперь повторяет то, что видит поисковик, и охватывает все публичные сущности Dharma Shop.

### Добавлено

- **Фильтр noindex.** Страница с `robots: noindex` в карту не попадает. Значение определяется так же, как при показе страницы: свои настройки записи → пункт меню → общие настройки Joomla (для Dharma Shop — настройка магазина). Включается настройкой «Не добавлять страницы с noindex» (по умолчанию включена), число исключённых страниц видно в отчёте.
- **Сущности Dharma Shop:** бренды, бейджи («метки») и посадочные страницы. Категории, бренды и бейджи без товаров пропускаются. При настройке магазина «главный вариант» (`seo_variant_canonical = main`) в карту попадает только главный вариант группы — тот, на который указывает canonical.
- **Страницы из меню:** главная, списки категорий, брендов, бейджей и посадочных, избранные материалы и другие пункты меню без собственного источника. Личные и служебные страницы (корзина, оформление заказа, избранное, заказы, оплата, поиск, вход и регистрация) в карту не попадают никогда.
- **Отчёт сборки** во вкладке «Обзор»: сколько адресов дал каждый источник и сколько исключено по каждой причине; предупреждение, если страницы закрыты noindex.
- **Очистка старых сборок:** строки БД, каталоги в Joomla Cache и версионные части в корне сайта. Настройка «Хранить сборок» (по умолчанию 3).
- **Тесты, проверка языковых файлов и CI** (проверка синтаксиса, манифестов, сборка пакета).

### Исправлено

- Адреса категорий содержали лишний `?catid=1`, а адрес одной из них отдавал 404: для вида `category` передавался `catid` родителя.
- Контакты Joomla не попадали в карту совсем: условие публикации проверяло колонку адреса `state`, а не `published`.
- Кириллические адреса портились (`parse_url` заменял часть байтов на «_»); теперь адрес кодируется до разбора.
- Страницы с ограниченным доступом определялись жёстким условием «уровень 1»; теперь используются реальные уровни гостя.
- Метки Joomla получали посторонний параметр `catid`.
- Сборка с настроенным каноническим доменом отбрасывала все URL: проверка хоста сравнивала его с основным адресом Joomla уже после замены.
- Шаблоны вида `mc_*` в списке удаляемых параметров не работали; параметры с точкой в имени портились.
- Блокировка сборки могла «залипнуть» на 30 минут, если не удавалась вставка записи сборки; теперь она снимается всегда и продлевается, пока сборка идёт.
- Пустые и нулевые даты превращались в `1970-01-01` в `lastmod`.
- Ошибка источника теперь называет его в сообщении.

### Производительность

- Адреса вставляются пачками (`INSERT IGNORE`) вместо двух запросов на каждый URL.
- Файлы карты пишутся ключевой выборкой по `id`, а не `LIMIT/OFFSET`, и не держат часть целиком в памяти; части делятся и по лимиту 50 МБ.
- Сборка не ограничена временем выполнения PHP и не обрывается закрытием вкладки.

### Изменения для разработчиков

- `SitemapSourceInterface` получил метод `getPriority()`; запись порции может содержать `robots`. Источники с меньшим приоритетом идут раньше, при совпадении адреса остаётся первая запись.
- Отчёт сборки теперь `{"sources": [...], "excluded": {...}}`; отчёты старых сборок читаются как раньше.
