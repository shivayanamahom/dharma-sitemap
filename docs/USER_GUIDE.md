# Руководство администратора

## Установка

Установите `pkg_dharmasitemap-<версия>.zip` через **Система → Установка → Расширения**. Пакет ставит компонент, базовые источники Joomla, интеграцию Dharma Shop, системный endpoint, плагины Scheduler и CLI. После установки включите нужные плагины Dharma Sitemap в **Система → Плагины**. Интеграция магазина не требует `com_dharmashop` и просто пропускает источники при его отсутствии.

## Первая сборка

Откройте **Компоненты → Dharma Sitemap**, нажмите **Собрать сейчас** и дождитесь сообщения об успехе. После успешной сборки компонент показывает количество URL и дублей, а также адрес XML sitemap index. До первой успешной сборки endpoint отвечает 503.

Во время новой сборки посетители продолжают получать прошлую успешную версию. Ошибка не активирует частичный набор.

## Источники и настройки

В настройках компонента можно включать материалы/категории, контакты, ленты новостей и метки Joomla, а также товары/категории Dharma Shop. В карту попадают только опубликованные записи с публичным уровнем доступа и опубликованными публичными категориями/родителями.

Необязательный канонический URL используется для выбора основного домена в `<loc>`. Указывайте корень сайта, например `https://example.com/`, без пути и query string. Параметры рекламных кампаний удаляются при нормализации. Значимые для маршрута параметры Joomla сохраняются.

После сборки компонент публикует статический `https://example.com/sitemap.xml` в корне сайта. При размере больше лимита он становится sitemap index и ссылается на версионные статические части `sitemap-<build>-<part>.xml`. Исходные файлы сборки также сохраняются в Joomla Cache, а старый Joomla endpoint оставлен как резерв. Существующий `sitemap.xml`, который не содержит маркер Dharma Sitemap, никогда не перезаписывается: сборка останавливается с пояснением.

## Настройки включения и исключения

На панели компонента нажмите **Настройки карты**. Во вкладке **Источники URL** отдельно включаются материалы/категории Joomla, контакты, ленты, метки, товары и категории Dharma Shop. Во вкладке **Исключения** задаются пути URL с `*` и `?` или конкретные сущности `provider:id`, по одному правилу на строку. Пример: `dharmashop.products:456`. Публичный доступ и публикация проверяются независимо и не отключаются этими фильтрами.

Канонический адрес, параметры отслеживания и размер части находятся в **Общих настройках**. Для автоматического времени нажмите **Расписание генерации** и настройте задачу Joomla Scheduler; сама генерация идёт по тому же координатору.

## Автоматическая сборка

В **Компоненты → Планировщик задач** создайте задачу **Пересобрать карту сайта Dharma Sitemap** и задайте интервал/время выполнения. Плагин использует те же настройки и логику, что ручной запуск.

## Запуск через Joomla CLI

Включите плагин **Dharma Sitemap — CLI** в списке плагинов. Из корневого каталога Joomla выполните:

```sh
php cli/joomla.php dharmasitemap:build
```

Команда использует те же источники, фильтры и блокировку, что и административный запуск и Scheduler. Код завершения `0` означает успешную публикацию; `1` означает ошибку.

## Плагины источников

Поставщики URL подключаются через группу `dharmasitemap` и событие `onDharmaSitemapCollectSources`. Контракт описан в [руководстве разработчика](DEVELOPER_GUIDE.md). Не добавляйте в источник закрытые страницы, варианты товаров, корзину, поиск и страницы личного кабинета.
