# Руководство администратора

## Установка

Установите `pkg_dharmasitemap-<версия>.zip` через **Система → Установка → Расширения**. Пакет ставит компонент, базовые источники Joomla, интеграцию Dharma Shop, системный endpoint и плагин задачи Scheduler. Интеграция магазина не требует `com_dharmashop` и просто пропускает источники при его отсутствии.

## Первая сборка

Откройте **Компоненты → Dharma Sitemap**, нажмите **Собрать сейчас** и дождитесь сообщения об успехе. После успешной сборки компонент показывает количество URL и дублей, а также адрес XML sitemap index. До первой успешной сборки endpoint отвечает 503.

Во время новой сборки посетители продолжают получать прошлую успешную версию. Ошибка не активирует частичный набор.

## Источники и настройки

В настройках компонента можно включать материалы/категории, контакты, ленты новостей и метки Joomla, а также товары/категории Dharma Shop. В карту попадают только опубликованные записи с публичным уровнем доступа и опубликованными публичными категориями/родителями.

Необязательный канонический URL используется для выбора основного домена в `<loc>`. Указывайте корень сайта, например `https://example.com/`, без пути и query string. Параметры рекламных кампаний удаляются при нормализации. Значимые для маршрута параметры Joomla сохраняются.

URL по умолчанию: `index.php?option=com_dharmasitemap&view=sitemap&format=xml`. Первая версия не меняет `.htaccess` или конфигурацию Nginx.

## Автоматическая сборка

В **Компоненты → Планировщик задач** создайте задачу **Пересобрать карту сайта Dharma Sitemap** и задайте подходящий интервал. Плагин использует те же настройки и логику, что ручной запуск.

## Плагины источников

Поставщики URL подключаются через группу `dharmasitemap` и событие `onDharmaSitemapCollectSources`. Контракт описан в [руководстве разработчика](DEVELOPER_GUIDE.md). Не добавляйте в источник закрытые страницы, варианты товаров, корзину, поиск и страницы личного кабинета.
