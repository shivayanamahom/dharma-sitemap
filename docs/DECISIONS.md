# Решения и вопросы для согласования

Статус: базовые решения реализованы в пакете `0.1.0`; вопросы расширения остаются открытыми.

## Предлагаемые решения

| Вопрос | Предложение | Почему |
|---|---|---|
| Имя | `Dharma Sitemap`, пакет `pkg_dharmasitemap`, компонент `com_dharmasitemap` | Понятное отдельное расширение с единым префиксом |
| Репозиторий | Публичный `shivayanamahom/dharma-sitemap` | Пользователь разрешил публичное размещение; feed и install ZIP доступны Joomla без авторизации |
| Формат поставки | Один пакет: компонент + source-плагины + Scheduler task plugin | Одна установка и согласованные версии; интеграция с Dharma Shop при этом остаётся независимым адаптером |
| Расширение | Отдельный plugin group `dharmasitemap`, стабильный source contract | Новые расширения добавляют источник, не меняя ядро |
| Сборка | Порционная, возобновляемая, с временным набором и атомарной публикацией | Большие каталоги, прерывания и сохранение последней рабочей карты |
| Защита от дублей | Ключ сущности + нормализованный URL + DB unique index | Защищает и от разных маршрутов, и от повторных запусков |
| Обновления | Joomla update server на публичном `updates.xml`, release ZIP и SHA-256 | Joomla может обнаружить и скачать обновление без GitHub token |
| Первые источники | Joomla content/contact/newsfeeds/tags и Dharma Shop товары/категории | Покрывает основные публичные страницы; остальные индексируемые core-компоненты добавляются отдельными provider-плагинами |

## Открытые вопросы для следующих версий

1. Какие типы меню Joomla считать источником адресов и использовать для выбора SEF-маршрута?
2. Добавлять ли `com_contact` и `com_newsfeeds` уже в MVP или начать с `com_content`?
3. Поведение при частичной ошибке: не публиковать сборку вообще либо разрешить публикацию с явным предупреждением и пропущенным источником?
4. Первичная доставка: URL `index.php?option=com_dharmasitemap&view=index&format=xml` или требуется поддержка короткого `/sitemap.xml` на первом релизе?
5. Нужно ли gzip-сжатие файлов карты в первой версии?
6. Какие страницы Dharma Shop должны индексироваться помимо товаров и категорий (бренды, страницы посадочных категорий)?
7. Политика вариантов товаров: исключить по умолчанию или включать только отдельные канонические варианты?
8. Расписание по умолчанию и ожидаемый предел размера каталога/частота обновления.

## Реализация MVP и оставшиеся ограничения

- Репозиторий и первичная установка — публичный `shivayanamahom/dharma-sitemap`; демонстрационная проверка согласована для `dharma-demo.ru`.
- Компонент уже предоставляет ручную кнопку генерации, а отдельный плагин Joomla Scheduler — задачу `Собрать XML-карту сайта`.
- Кандидаты поставляются одной plugin group `dharmasitemap`; пакет включает core source plugin, необязательный адаптер Dharma Shop, system plugin выдачи XML и task plugin планировщика.
- MVP собирает одну версию синхронно в рамках одного запроса Scheduler/администратора. Возобновление по cursor между запусками пока не реализовано.
- Карта публикуется через `index.php?option=com_dharmasitemap&view=sitemap&format=xml`; короткий `/sitemap.xml` не настраивается автоматически.
- До проверки на стенде не считаем подтверждёнными: успешную регистрацию plugin group на Joomla 6.2, наличие всех источников в конкретной конфигурации, сборку и XML-ответ по реальным данным, видимость задачи Scheduler и обновление через Joomla update manager.

## Пока не считаем решённым

- Нет подтверждённой схемы публичных маршрутов Dharma Shop для товаров, категорий и брендов.
- Не утверждён перечень типов Joomla меню, алиасов, языков и query-параметров для маршрутизации.
- Не выбрано, будет ли alias `/sitemap.xml` включён в пакет автоматически через конфигурацию web-server. По умолчанию компонент не редактирует `.htaccess`, Nginx или системную конфигурацию.
- Не утверждены сроки хранения предыдущих файлов и журналов, размер порции и лимиты на сайт.
- Публичность репозитория утверждена; наличие в истории пакетов персональных данных или производственных секретов недопустимо.
