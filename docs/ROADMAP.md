# План Dharma Sitemap

Состояние на 2026-10-16. Ранняя проверка компонента и Scheduler прошла на `dharma-demo.ru`. Статическая публикация `/sitemap.xml`, настройки генерации и включение CLI-плагина входят в текущую обновлённую сборку и ожидают проверки после установки.

## Этап 0. Согласовать MVP

- Зафиксировать MVP-границы из `DECISIONS.md`.
- Пройти таблицы и публичную маршрутизацию Dharma Shop, не копируя его внутренние реализации без проверки контракта.
- Зафиксировать поддерживаемые меню, виды страниц, фильтры индексации, endpoint, лимиты и поведение при ошибке.

## Этап 1. Каркас и ручная генерация

- Пакет Joomla с `com_dharmasitemap`, библиотечным source contract, таблицами сборок/журналов и встроенным диспетчером плагинов.
- Админ-интерфейс на Form XML/штатных Joomla toolbar и Bootstrap.
- Первый источник Joomla Content (материалы + категории), нативная маршрутизация и общие SEO/ACL-фильтры.
- XML writer, sitemap index и разбиение на части; ручной пакетный запуск и атомарная активация.
- Диагностика дублей, ошибок/счётчиков и результатов сборки.

## Этап 2. Интеграции и автоматизация

- Плагины Contact и Newsfeeds, если подтверждены в MVP.
- Адаптер Dharma Shop для согласованных публичных сущностей.
- Task plugin с возобновлением и lock; настройка расписания и лимита работы.
- Исключения по URL/сущности/категории и отчёт о канонических конфликтах.

## Этап 3. Релиз и update server

- Воспроизводимый `build.sh`, проверка manifests/архива и проектная документация для пользователей и разработчиков.
- GitHub Actions: build → checksum → release → обновление публичного `updates.xml`.
- Ранняя сборка на demo Joomla, ручная генерация, XML endpoint и тестовая Scheduler-задача проверены. Статическая публикация и CLI на сервере проверяются в обновлённом пакете.
- Проверить CLI-плагин после установки пакета, затем создать первый tag и install ZIP.

## Этап 4. Позже, если понадобится

- Gzip, `lastmod` точнее из событий изменения, дополнительных providers (например, сторонние каталоги), уведомления поисковых систем.
- Настраиваемый UI-preview карты и отчёт сравнения двух сборок.
- Большие установки: оценка индексов/порций и внешний storage adapter.

## Условия перехода к этапу 1

Код не начинается до подтверждения MVP: содержимого первой версии, правил при ошибке источника, требований к endpoint и маршрутизации Dharma Shop. Это удерживает базовый контракт плагинов и схему публикации от переписывания после появления первого адаптера.
