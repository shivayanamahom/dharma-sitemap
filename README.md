# Dharma Sitemap

Расширяемый генератор XML-карт сайта для Joomla: ядро Joomla, Dharma Shop и сторонние источники URL через плагины.

> Статус: пакет `0.2.1` установлен на `dharma-demo.ru` (Joomla 6.2.0): ручная сборка дала 97 URL, тестовая Scheduler-задача выполнилась. CLI-плагин входит в пакет. Для карты из одной части корневой файл напрямую содержит URL; для больших карт используется индекс.

## Что входит в MVP

- `com_dharmasitemap` — настройки, управление сборками, диагностика и публичная выдача XML.
- Поставщики URL для материалов и категорий Joomla, Dharma Shop и сторонних расширений.
- Защита от дублей URL и сущностей, безопасная повторяемая генерация и сохранение последней рабочей карты.
- Пакет сборки и Joomla update server: публичный `updates.xml`, install ZIP в GitHub Releases, проверка SHA-256.
- Ручная сборка в панели компонента и автоматическая сборка через Joomla Scheduler Task.
- Команда Joomla CLI `dharmasitemap:build`, использующая тот же координатор сборки.
- Физический `/sitemap.xml` в web root: один файл содержит URL напрямую; при большом количестве URL публикуется sitemap index с версионными частями. При наличии чужого файла публикация останавливается без перезаписи.

## Статус

Репозиторий создан как публичный по прямому разрешению владельца. Установочный пакет находится в `dist/`; его содержимое можно собрать повторно командой `./build.sh`.

## Запуск через CLI

Включите плагин **Dharma Sitemap — CLI** в **Система → Плагины**, затем из корня Joomla выполните:

```sh
php cli/joomla.php dharmasitemap:build
```

Команда вернёт ненулевой код завершения и сообщение об ошибке, если сборку не удалось опубликовать.
